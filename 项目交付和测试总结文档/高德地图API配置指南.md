# 高德地图API配置指南

## 1. 获取高德地图API密钥

### 步骤1：注册高德地图开发者账号
1. 访问 [高德开放平台](https://lbs.amap.com/)
2. 注册并登录开发者账号
3. 完成实名认证

### 步骤2：创建应用
1. 进入控制台 → 应用管理 → 我的应用
2. 点击"创建新应用"
3. 填写应用信息：
   - 应用名称：智能医生系统
   - 应用类型：Web服务

### 步骤3：添加Key
1. 在应用详情页点击"添加"
2. 选择服务类型：Web服务
3. 获取API Key（通常以"key="开头的一串字符）

## 2. 配置项目环境变量

### 方法1：修改.env文件
编辑项目根目录下的`.env`文件：

```env
# 高德地图API配置
AMAP_API_KEY=你的高德地图API密钥

# 其他配置保持不变
DEBUG=True
SECRET_KEY=django-insecure-development-key
# ...
```

### 方法2：系统环境变量（推荐用于生产环境）

**Windows系统：**
```cmd
setx AMAP_API_KEY "你的高德地图API密钥"
```

**Linux/Mac系统：**
```bash
export AMAP_API_KEY="你的高德地图API密钥"
```

## 3. 验证配置


## 4. API功能说明

### 已集成的API服务

1. **地理编码（Geocoding）**
   - 功能：地址转经纬度
   - 用途：用户地址定位

2. **逆地理编码（Reverse Geocoding）**
   - 功能：经纬度转地址
   - 用途：位置信息显示

3. **天气查询（Weather）**
   - 功能：获取城市天气信息
   - 用途：预约日天气提醒

4. **路径规划（Route Planning）**
   - 功能：计算出行路线
   - 用途：医院导航服务

### API调用限制

- 免费版每日调用限额：5,000次
- 并发限制：50次/秒
- 建议添加缓存机制减少API调用

## 5. 故障排除

### 常见错误及解决方案

**错误：INVALID_USER_KEY**
- 原因：API密钥无效或未配置
- 解决：检查.env文件中的AMAP_API_KEY配置

**错误：DAILY_QUERY_OVER_LIMIT**
- 原因：超过每日调用限额
- 解决：添加缓存或升级API套餐

**错误：SERVICE_NOT_AVAILABLE**
- 原因：服务暂时不可用
- 解决：稍后重试或使用备用服务

## 6. 开发建议

### 缓存策略
- 对地理编码结果进行本地缓存（24小时）
- 对天气数据进行缓存（1小时）
- 使用Redis或数据库存储缓存数据

### 错误处理
- 实现优雅降级机制
- API不可用时使用模拟数据
- 记录API调用日志用于监控

### 性能优化
- 批量处理地址解析请求
- 使用CDN加速API响应
- 合理设置请求超时时间
