## 🔧 技术实现细节

### 前端技术栈
- **框架**: 微信小程序原生开发
- **样式**: WXSS + CSS变量系统
- **网络**: 封装请求工具，支持拦截器
- **存储**: 本地缓存 + 状态管理

### 后端技术栈
- **框架**: Django + Django REST Framework
- **数据库**: SQLite (开发) / MySQL (生产)
- **认证**: Token认证机制
- **API**: RESTful风格接口
