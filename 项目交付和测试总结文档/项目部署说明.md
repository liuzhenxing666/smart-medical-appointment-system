# 智慧医疗预约平台 - 项目部署说明

## 项目概述

本项目是一个基于微信小程序的智慧医疗预约平台，包含完整的医院管理、医生管理、预约管理、用户管理等功能模块。

### 技术栈
- **前端**: 微信小程序原生开发
- **后端**: Django REST Framework
- **数据库**: SQLite (开发环境) / MySQL (生产环境)
- **部署**: 本地开发环境

## 部署步骤

### 1. 环境准备

#### 后端环境
```bash
# 确保Python环境
python --version
# Python 3.8+

# 安装依赖
pip install -r requirements.txt

# 数据库迁移
python manage.py makemigrations
python manage.py migrate

# 创建超级用户
python manage.py createsuperuser
```

#### 前端环境
- 微信开发者工具
- 小程序AppID（需要申请）

### 2. 后端启动

```bash
# 启动Django开发服务器
python manage.py runserver 0.0.0.0:8000
```

### 3. 前端配置

1. 打开微信开发者工具
2. 导入项目：选择 `miniprogram-frontend` 目录
3. 配置AppID（如无可用使用测试号）
4. 修改 `utils/request.js` 中的 BASE_URL
5. 配置合法域名（需要在小程序后台配置）

### 4. 测试验证

1. **功能测试**
   - 首页定位和推荐功能
   - 医院和医生搜索
   - 用户登录和预约流程
   - 错误页面处理

2. **接口测试**
   - 确保所有API接口正常响应
   - 验证数据格式和错误处理

3. **兼容性测试**
   - 不同设备尺寸适配
   - 网络环境测试

## 常见问题解决

### 1. 位置权限问题
- 确保小程序已授权位置权限
- 检查设备GPS是否开启

### 2. 网络请求失败
- 检查BASE_URL配置
- 验证后端服务是否运行
- 检查网络连接

### 3. 页面白屏
- 检查页面路径配置
- 验证组件引入是否正确
- 查看控制台错误信息

### 4. 数据加载失败
- 检查API接口响应格式
- 验证数据解析逻辑
- 查看网络请求详情
