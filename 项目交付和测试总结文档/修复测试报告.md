## 6. 登录接口500错误修复

### 问题描述
- 登录接口 POST `/api/users/auth/login/` 返回500 Internal Server Error
- 错误信息：`MultipleObjectsReturned: get() returned more than one User -- it returned 2!`

### 根本原因
- 数据库中存在重复手机号的用户记录
- `users/models.py`中`phone`字段未设置`unique=True`约束
- 导致登录时根据手机号查询用户时返回多个结果

### 修复方案
1. **修改用户模型**：在`users/models.py`中为`phone`字段添加`unique=True`约束
2. **清理重复数据**：创建清理脚本删除重复用户记录
3. **应用数据库迁移**：生成并应用迁移文件

### 修复过程
- 发现3组重复手机号用户（13800138000、13800138001、13888888888）
- 清理脚本保留最早创建的用户，删除重复用户
- 从14个用户清理到11个用户，确保手机号唯一性
- 成功应用迁移：`users.0003_alter_user_phone`

### 测试结果
- ✅ 登录接口正常返回JWT token
- ✅ 错误信息："登录成功"
- ✅ 状态码：200 OK
