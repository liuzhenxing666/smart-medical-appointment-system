# 微信小程序开发优化指南

## 问题说明
您遇到的问题是微信开发者工具的正常工作机制：**每次代码修改后需要重新上传才能在真机调试中看到效果**。

## 解决方案

### 1. 使用模拟器进行开发（推荐）
- 在微信开发者工具中直接使用模拟器进行开发
- 修改代码后，模拟器会自动刷新显示最新效果
- 不需要每次都上传到真机

### 2. 启用热重载功能
```javascript
// 在微信开发者工具中：
// 设置 → 项目设置 → 开启"热重载"
// 设置 → 项目设置 → 开启"自动保存"
```

### 3. 使用开发监控脚本
我已经为您创建了 `dev-script.js`，可以监控文件变化：

```bash
# 在项目根目录运行
node dev-script.js
```

这个脚本会：
- 监控所有 `.js`, `.wxml`, `.wxss`, `.json` 文件的变化
- 自动提示您需要重新编译
- 显示文件修改时间

### 4. 优化开发工作流程

#### 开发阶段（频繁修改）
1. 使用模拟器进行开发
2. 修改代码后，模拟器自动刷新
3. 只在需要真机测试时上传

#### 测试阶段（功能验证）
1. 完成一个功能模块后
2. 点击"预览"或"真机调试"
3. 在手机上验证功能

#### 发布阶段
1. 所有功能测试通过后
2. 点击"上传"
3. 在微信小程序后台提交审核

## 常见问题解决

### Q: 修改后真机看不到变化？
A: 这是正常现象，需要重新上传。建议使用模拟器开发。

### Q: 网络请求失败？
A: 检查后端服务是否运行：`http://127.0.0.1:8000`

### Q: 图标不显示？
A: 需要将占位图标替换为真实图标文件
