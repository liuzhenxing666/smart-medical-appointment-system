## 🛠️ 部署步骤

### 第一步：环境准备
```bash
# 1. 安装Python 3.8+
python --version

# 2. 安装依赖包
pip install -r requirements.txt

# 3. 安装PostgreSQL (Windows)
# 下载地址: https://www.postgresql.org/download/windows/
```

### 第二步：数据库配置
```bash
# 1. 运行快速安装脚本
quick_postgres_setup.bat

# 2. 或手动配置
python postgresql_setup.py
```

### 第三步：环境变量配置
编辑 `.env` 文件：
```env
# PostgreSQL数据库配置
DB_NAME=smart_doctor
DB_USER=postgres
DB_PASSWORD=your_secure_password
DB_HOST=localhost
DB_PORT=5432

# Redis缓存配置
REDIS_URL=redis://127.0.0.1:6379/1

# 微信小程序配置
WECHAT_APP_ID=your_wechat_app_id
WECHAT_APP_SECRET=your_wechat_app_secret

# 腾讯地图配置
TENCENT_MAP_API_KEY=your_tencent_map_api_key

# Django安全配置
DEBUG=False
SECRET_KEY=your-production-secret-key-here
ALLOWED_HOSTS=localhost,127.0.0.1,your-domain.com
```

### 第四步：启动服务
```bash
# 开发环境
python manage.py runserver 0.0.0.0:8000

# 生产环境 (使用Gunicorn)
gunicorn smart_doctor.wsgi:application --bind 0.0.0.0:8000 --workers 4
```

### 1. SSL/TLS配置
```nginx

    listen 443 ssl;
    server_name your-domain.com;
    
    ssl_certificate /path/to/certificate.crt;
    ssl_certificate_key /path/to/private.key;
```

### 2. 防火墙配置
```bash
# 开放必要端口
ufw allow 8000/tcp
ufw allow 5432/tcp  # PostgreSQL

```

### 3. 数据库安全
```sql

GRANT USAGE ON SCHEMA public TO smart_doctor_user;
GRANT SELECT, INSERT, UPDATE, DELETE ON ALL TABLES IN SCHEMA public TO smart_doctor_user;
```

## 🚨 故障排除

### 常见问题及解决方案

#### 1. 数据库连接失败
```bash
# 检查PostgreSQL服务状态
sudo systemctl status postgresql

# 检查连接参数
python manage.py dbshell
```

#### 2. JWT认证失败
```bash
# 检查SECRET_KEY配置
echo $SECRET_KEY

# 重新生成SECRET_KEY
python -c "from django.core.management.utils import get_random_secret_key; print(get_random_secret_key())"
```

#### 3. 腾讯地图API失败
```bash
# 检查API密钥
curl "https://apis.map.qq.com/ws/geocoder/v1/?key=YOUR_KEY&address=北京市"
```
