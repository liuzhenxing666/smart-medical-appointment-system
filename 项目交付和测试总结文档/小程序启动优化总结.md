# 小程序启动优化总结

## 问题分析

**原始问题：** 小程序启动时间7009ms，17个图片文件加载返回500错误

**根本原因：**
1. 图片路径配置错误：小程序使用相对路径`/images/xxx.jpg`，但服务器实际路径为`/static/images/xxx.jpg`
2. 网络超时：小程序默认超时时间10秒，图片并发加载过多导致超时
3. 图片加载策略：无预加载和懒加载优化

## 解决方案

### 1. 图片路径修正
- 将所有图片路径从相对路径改为完整URL：
  - `'/images/banner1.jpg'` → `'http://127.0.0.1:8000/static/images/banner1.jpg'`
  - 涉及banners、tcmServices、hotHospitals、recommendDoctors、healthArticles等模块

### 2. 网络超时优化
- 将小程序网络超时时间从10秒延长到15秒：
  - `request: 15000`
  - `downloadFile: 15000` 
  - `uploadFile: 15000`

### 3. 图片加载策略优化

#### 预加载关键图片
- 在页面加载时预加载轮播图和中医图标等关键图片
- 分批加载（每批3张），避免同时请求过多
- 使用`wx.downloadFile`进行预加载

#### 懒加载所有图片
- 为所有`<image>`组件添加`lazy-load="{{true}}"`属性
- 包括轮播图、服务图标、医院图片、医生头像、文章配图等

#### 数据加载优化
- 从并行加载改为串行加载，避免同时请求过多
- 先加载热门医院，再加载推荐医生，最后加载健康资讯

## 技术要点

### 图片路径配置
```javascript
// 修改前
image: '/images/banner1.jpg'

// 修改后  
image: 'http://127.0.0.1:8000/static/images/banner1.jpg'
```

### 预加载实现
```javascript
preloadCriticalImages() {
  const criticalImages = [
    'http://127.0.0.1:8000/static/images/banner1.jpg',
    // ... 其他关键图片
  ]
  
  // 分批预加载
  const batchSize = 3
  for (let i = 0; i < criticalImages.length; i += batchSize) {
    const batch = criticalImages.slice(i, i + batchSize)
    batch.forEach(imageUrl => {
      wx.downloadFile({
        url: imageUrl,
        success: () => console.log('图片预加载成功:', imageUrl),
        fail: (err) => console.warn('图片预加载失败:', imageUrl, err)
      })
    })
  }
}
```

### 懒加载配置
```xml
<image src="{{item.image}}" lazy-load="{{true}}" />
```
