# 智能医生预约系统 - 项目验收总结报告

## 项目概述

本项目是一个基于Django框架的智能医生预约系统，集成了医院信息爬虫、医生排班管理、用户预约、数据统计监控等功能，为患者提供便捷的在线预约服务。

## 部署和运行说明

### 环境要求
- Python 3.8+
- Django 5.1.2
- 相关依赖包（详见requirements.txt）

### 启动步骤
1. 安装依赖：`pip install -r requirements.txt`
2. 数据库迁移：`python manage.py migrate`
3. 创建管理员：`python manage.py createsuperuser`
4. 启动服务：`python manage.py runserver`
5. 访问管理后台：http://localhost:8000/admin/

### 测试验证
- 运行预约功能测试：`python test_appointment_api.py`
- 运行爬虫功能测试：`python test_web_crawler.py`
- 运行管理界面测试：`python test_admin_interface.py`
