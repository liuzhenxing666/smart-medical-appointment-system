## 🗄️ 数据库选型与配置

### 数据库选择
- **主数据库**：PostgreSQL 15.x
- **缓存数据库**：Redis 7.x
- **选择理由**：
  - PostgreSQL支持JSON类型，适合存储地理位置和MCP返回数据
  - 强大的空间数据扩展（PostGIS）
  - 成熟的事务支持和数据一致性


## 📊 数据表详细设计

### 1. 用户表 (users)

**表说明**：存储系统用户信息，包括患者和管理员

| 字段名 | 类型 | 约束 | 说明 | MCP关联 |
|--------|------|------|------|----------|
| id | BIGSERIAL | PRIMARY KEY | 用户ID | - |
| username | VARCHAR(50) | UNIQUE, NOT NULL | 用户名 | - |
| phone | VARCHAR(15) | UNIQUE, NOT NULL | 手机号 | - |
| password | VARCHAR(128) | NOT NULL | 密码（加密） | - |
| location | JSONB | NULL | 用户位置信息 | 高德地图MCP |
| preferences | JSONB | DEFAULT '{}' | 用户偏好设置 | - |
| created_at | TIMESTAMP | DEFAULT NOW() | 创建时间 | - |
| updated_at | TIMESTAMP | DEFAULT NOW() | 更新时间 | - |

**索引设计**：
```sql
CREATE INDEX idx_users_phone ON users(phone);
CREATE INDEX idx_users_location ON users USING GIN(location);
```

**负责Agent**：数据库架构师

### 2. 医院表 (hospitals)

**表说明**：存储医院基本信息，包含地理位置数据

| 字段名 | 类型 | 约束 | 说明 | MCP关联 |
|--------|------|------|------|----------|
| id | BIGSERIAL | PRIMARY KEY | 医院ID | - |

| level | VARCHAR(20) | NOT NULL | 医院等级 | - |
| address | VARCHAR(200) | NOT NULL | 详细地址 | 高德地图MCP |
| longitude | DECIMAL(10,6) | NOT NULL | 经度 | 高德地图MCP |
| latitude | DECIMAL(10,6) | NOT NULL | 纬度 | 高德地图MCP |
| contact_phone | VARCHAR(20) | NULL | 联系电话 | Web爬虫MCP |
| description | TEXT | NULL | 医院描述 | Web搜索MCP |
| mcp_data | JSONB | DEFAULT '{}' | MCP原始数据 | 所有MCP |
| is_active | BOOLEAN | DEFAULT TRUE | 是否激活 | - |

### 6. 预约记录表 (appointments)

**表说明**：存储用户预约记录，包含完整预约信息

| 字段名 | 类型 | 约束 | 说明 | MCP关联 |
|--------|------|------|------|----------|

## 🔄 数据流设计

### MCP数据集成流程
```
用户请求 → 检查缓存 → 调用MCP API → 数据清洗 → 存储数据库 → 返回前端
```

### 数据更新策略
- **实时数据**：用户位置、天气信息（缓存5分钟）
- **准实时数据**：医生排班、评价数据（缓存1小时）
- **静态数据**：医院信息、科室信息（缓存24小时）

## 📈 性能优化方案

### 查询优化
```sql
-- 地理位置查询优化
SELECT * FROM hospitals 
WHERE ST_DWithin(
    ST_SetSRID(ST_MakePoint(longitude, latitude), 4326),
    ST_SetSRID(ST_MakePoint(116.3974, 39.9093), 4326),
    5000  -- 5公里范围内
);

-- 分页查询优化
SELECT * FROM doctors 
ORDER BY average_rating DESC 
LIMIT 20 OFFSET 0;
```

### 索引策略
- **主键索引**：所有表的主键
- **外键索引**：所有外键关系
- **复合索引**：常用查询条件组合
- **GIN索引**：JSONB字段全文搜索
- **空间索引**：地理位置查询
